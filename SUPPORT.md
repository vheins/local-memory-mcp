## 🐛 GitHub Issues

Use [GitHub Issues](https://github.com/vheins/local-memory-mcp/issues) to:

- **Report bugs** — include your OS, Node.js version, and steps to reproduce.
- **Request features** — label the issue `enhancement` and describe the use case.

Before opening an issue, please:

1. Search existing issues to avoid duplicates.
2. Follow the issue guidelines in [CONTRIBUTING.md](CONTRIBUTING.md).

> ⚠️ **Security vulnerabilities must NOT be reported as public issues.** See
> [SECURITY.md](SECURITY.md) for private reporting instructions.
